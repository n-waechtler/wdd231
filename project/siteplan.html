MTG Utah Chapter

A project plan for a Magic the Gathering local community page.

Site Name

This name represents a game many people enjoy and for a local community to connect.

Site Purpose

The purpose of this site is for fans to connect, learn, find local game stores, and find local events.

Scenarios

• Where can I find a game store in the area?

• How long has Magic the Gathering been around?

• Where can I find local events?

• How do I know when new sets come out?
